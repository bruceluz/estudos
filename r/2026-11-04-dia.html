Algoritmos (Guanabara, aulas #01 e #02)

Algoritmo é uma sequência finita e organizada de passos que, executada na ordem certa, resolve um problema. A definição citada na aula é a do autor Manzano. A ordem importa: no exemplo de atravessar a rua, os mesmos passos em outra ordem ("atravesse" antes de olhar) deixam de resolver o problema, então deixam de ser um algoritmo.

Na aula #02, o foco passa para o algoritmo computacional: passos seguidos por um módulo processador (qualquer coisa programável: PC, celular, tablet) e seus usuários para realizar uma tarefa. Todo sistema nasce da lógica de programação (na cabeça de quem programa), que depois é escrita numa linguagem.

Formas de representar a lógica: fluxograma, diagrama de Chapin (Nassi-Shneiderman) e pseudocódigo. Em português, o pseudocódigo é o Portugol — que não é linguagem de programação, e sim uma forma de escrever a lógica. A ferramenta do curso é o VisuAlg.

Pontos práticos:

  • escreva mostra na tela sem pular linha; escreval mostra e pula linha.
  • Variável é um espaço na memória com etiqueta (identificador) e tipo, como uma gaveta de armário. Cabe um valor por vez.
  • 6 regras do identificador: começar com letra; depois letras ou números; nenhum símbolo exceto _; sem espaço; sem acento; não pode ser palavra reservada.
  • 4 tipos primitivos: inteiro, real (com ponto, ex.: 0.5), caractere (entre aspas, até "123") e lógico (verdadeiro/falso).
  • Atribuição: msg <- "Olá, Mundo!". Escrever "msg" com aspas mostra o texto msg; sem aspas mostra o conteúdo da variável.

TOTVS — Programação MVC, Módulo 1 (aulas 1 a 3)

O Protheus funciona em camadas: Client (SmartClient instalado ou WebApp no navegador) → Application Server → DBAccess → banco de dados (no curso, SQL Server). O RPO guarda os programas compilados; o fonte só vale depois de compilado. O dicionário de dados (SX) descreve tabelas e campos; por isso mudar a estrutura de um campo não exige compilar. O DBAccess não é banco: é a ponte, e usa ODBC.

Ligação entre os dois: o "fonte" que o programador escreve no Protheus é a lógica de programação escrita numa linguagem (ADVPL), exatamente o caminho que o Guanabara descreveu: lógica → linguagem → sistema.

Algoritmos
1. Pela definição apresentada na aula #01, o que é um algoritmo?
Algoritmo é uma sequência finita e organizada de passos que resolve um problema. Não precisa ser complexo nem envolver computador.
Algoritmos
2. No exemplo de atravessar a rua, por que a versão que começa com "atravesse" não é considerada um algoritmo?
A ordem dos passos é parte do algoritmo. Atravessar antes de olhar não resolve o problema com segurança.
Algoritmos
3. O que é o Portugol?
Portugol é pseudocódigo em português. Ele representa a lógica antes de você passar para uma linguagem real.
Algoritmos
4. Qual é a diferença entre escreva e escreval no VisuAlg?
O L de escreval significa linha: escreve e salta a linha. O escreva deixa as mensagens lado a lado.
Algoritmos
5. Qual destes identificadores é VÁLIDO no VisuAlg?
Inicio_Algoritmo começa com letra, não tem acento, espaço nem símbolo (o _ é permitido) e não é palavra reservada. Média tem acento; 9dade começa com número; Salário Bruto tem acento e espaço.
Algoritmos
6. Em Portugol, "123" escrito entre aspas é de que tipo?
Tudo que está entre aspas é cadeia de caracteres, mesmo que pareçam números.
Algoritmos
7. Se a variável msg contém "Olá, Mundo!", o que aparece na tela com escreva("msg")?
Com aspas, msg é um texto fixo e é mostrado literalmente. Para mostrar o conteúdo da variável, escreva(msg) sem aspas.
TOTVS
8. Na arquitetura do Protheus, qual peça executa as rotinas e regras do sistema?
O Application Server é o cérebro: busca o programa no RPO e executa. O SmartClient só mostra a tela.
TOTVS
9. Um programador alterou o fonte de uma rotina e não compilou. O que o usuário vê?
O servidor executa o que está compilado no RPO. Fonte alterado sem compilar não muda nada para o usuário.
TOTVS
10. Qual é a função do DBAccess?
O DBAccess (antigo Top Connect) não é banco: leva os pedidos do Application Server ao banco e traz as respostas.
